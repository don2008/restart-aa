# Reštart AA

Jednoduchá Android aplikácia pre rýchly prístup k systémovej obrazovke Android Auto.

Po ťuknutí na ikonu otvorí priamo **Android Auto → Informácie o aplikácii**, kde možno zvoliť **Vynútiť zastavenie**. Android Auto sa znovu aktivuje pri ďalšom pripojení k vozidlu.

## Dôležité obmedzenie

Android nedovoľuje bežnej aplikácii bez rootu alebo privilegovanej služby automaticky zastaviť inú aplikáciu. Preto je potvrdenie tlačidla **Vynútiť zastavenie** systémovým krokom používateľa.

Aplikácia nevyžaduje internet ani prístup k osobným údajom.
